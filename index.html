Pomo Cam

뽀모도로 타이머 겸 나의 집중 모먼트 기록!

Pomo Cam은 25분 집중 + 5분 휴식을 두 번 도는 뽀모도로 사이클을 화면 전체를 채우는 큰 다이얼로 보여주는 무료 웹 도구입니다. 브라우저만 있으면 설치 없이 바로 쓸 수 있고, 원하는 배경을 선택하여 사용할 수 있습니다.

주요 기능

  • 25분 세션 2회 + 5분 휴식 2회로 구성된 60분 뽀모도로 사이클
  • 화이트 / 블루 배경 전환, 실제 웹캠 배경 켜기/끄기
  • 세션 전체를 일정 간격으로 캡처해 타임랩스 영상(webm)으로 저장
  • OBS 같은 방송 소프트웨어의 브라우저 소스로 바로 사용 가능

사용법

  • 화면 아래 BEGIN을 눌러 타이머 시작, RESET으로 처음부터
  • REC으로 타임랩스 녹화 시작, 끝나면 SAVE로 영상 저장
  • CAMERA로 내 웹캠을 배경으로 전환 (브라우저 권한 허용 필요)
  • 오른쪽 아래 ? 버튼에서 전체 단축키 확인 가능

배경

  • 화이트 — 어떤 화면에도 무난하게 어울리는 기본 배경
  • 블루 — 집중력과 기억력 향상에 도움이 된다고 알려진 색으로, 학습·암기 세션에 추천
  • 웹캠 — 타이머에 맞추어 작업 모습을 그대로 녹화

BG 버튼으로 언제든 전환할 수 있습니다.

뽀모도로 기법이란?

1980년대 프란체스코 시릴로가 고안한 시간관리 기법으로, 25분 집중과 5분 휴식을 반복해 짧은 리듬으로 몰입을 유지하는 방식입니다. Pomo Cam은 이 리듬을 초 단위로 정확히 재생하면서, 동시에 그 시간의 흐름을 타임랩스 영상으로 남길 수 있게 만들었습니다.
